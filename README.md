# Khasab Coffee Roasters

أنت مهندس برمجيات أول ومصمم واجهات وتجربة مستخدم (UI/UX) محترف. قم ببناء وتطوير متجر إلكتروني متكامل، حديث وفائق السرعة باللغة العربية بالكامل وباتجاه (RTL) لعلامة تجارية متخصصة في بيع محاصيل وآلات وأدوات القهوة المختصة باسم: "خصب" (Khasab).

==================================================

1. الهوية البصرية ونظام الألوان (مستوحى من الشعار)

==================================================

- اللون الأساسي: الأزرق الداكن / البترولي الفاخر (#0E3B43 / #12343B).

- اللون الثانوي / التمييزي: الكراميل / التراكوتا الدافئ (#BA7A3B / #C58344).

- لون الخلفية العام: بيج كريمي هادئ وناعم (#FBF7F0 / #F5EDE0).

- البطاقات والعناصر: أبيض نقي (#FFFFFF) مع لمسات زجاجية خفيفة (Glassmorphism) وحدود دقيقة وظلال ناعمة.

- الخطوط: خط عربي عصري أنيق ومقروء مثل (Alexandria أو Readex Pro أو Tajawal).

- الشعار: دائري يحتوي على رسم أوراق شجرة البن مع كلمة "خصب" بخط عربي انسيابي.

==================================================

2. التأثيرات الحركية والعناصر ثلاثية الأبعاد (3D & Motion)

==================================================

- عناصر ثلاثية الأبعاد تفاعلية (Spline / Three.js / React Three Fiber):

  - مجسم ثلاثي الأبعاد تفاعلي في واجهة البداية (Hero Section) لمطحنة قهوة أو آلة إسبريسو أو حبوب بن تطفو وتتحرك مع حركة الماوس (Parallax 3D Effect).

  - بطاقات منتجات بتقنية الإمالة ثلاثية الأبعاد (3D Tilt Effect) عند تمرير الفأرة (Hover).

- التأثيرات الحركية (Framer Motion):

  - شريط إعلاني متحرك لا نهائي وسلس أعلى الموقع (Infinite Marquee Ticker) لعرض الإعلانات والشحن المجاني.

  - انتقالات سلسة بين الصفحات وظهور ناعم للبطاقات عند التمرير (Scroll-triggered Staggered Fade-in).

  - أيقونات حركية تفاعلية عند الإضافة للسلة أو النقر على الأزرار (Micro-interactions).

==================================================

3. تصنيفات المتجر وتخصيص المنتجات

==================================================

- التصنيفات:

  1. آلات الإسبريسو الفاخرة

  2. مطاحن القهوة الاحترافية

  3. أدوات التحضير المقطرة (V60، Chemex، أباريق الترشيح)

  4. محاصيل البن المختصة

  5. الفلاتر وإكسسوارات الباريستا

- صفحة تفاصيل المنتج:

  - للبن: خيارات تحديد نوع الطحنة (حبوب كاملة، إسبريسو، V60، فرنش بريس)، واختيار الوزن (250 جرام، 1 كيلو) مع تغير تلقائي في السعر، وعرض إيحاءات النكهة والارتفاع والمعالجة.

  - للآلات والأدوات: اختيار الألوان، المواصفات الفنية، وجدول مقارنة.

==================================================

4. سلة الشراء، الخرائط، ونظام الحسابات

==================================================

- نظام تسجيل الدخول:

  - تسجيل سريع برقم الجوال، أو إتمام الطلب مباشرة بخيار "الشراء كضيف" دون إجبار العميل على التسجيل المسبق.

- تحديد الموقع الجغرافي (Maps Integration):

  - خياران للاستلام: "توصيل للمنزل" أو "استلام من الفرع".

  - زر "تحديد موقعي التلقائي" لجلب إحداثيات الـ GPS فوراً وعرض الخريطة بنمط ألوان يتناسق مع ألوان المتجر، مع إمكانية سحب الدبوس يدوياً وإضافة ملاحظات العنوان.

==================================================

5. بوابة التحويلات البنكية والمحافظ المخصصة

==================================================

- شاشة إتمام الدفع (Manual Bank Transfer Gateway):

  - عرض حسابات المتجر بوضوح مع زر نسخ رقم الحساب بنقرة واحدة (بنك الكريمي، بنك القطيبي، ون كاش، جيب).

  - نموذج تأكيد الإيداع:

    - حقل: رقم العملية / الحوالة.

    - حقل: اسم المودع أو المحوّل.

    - حقل: رقم هاتف العميل للتواصل.

    - خاصية رفع صورة السند أو إشعار التحويل البنكي بسهولة (Drag & Drop / Camera Upload).

  - شاشة تأكيد الطلب الفورية مع إصدار رقم الطلب ورابط مباشر للتواصل عبر الواتساب.

==================================================

6. لوحة التحكم والإدارة (Admin Dashboard)

==================================================

- إدارة لحظية لحالات الطلبات (جديد، بانتظار التحقق من الحوالة، قيد التجهيز، قيد التوصيل، مكتمل).

- معاينة سريعة لبيانات الحوالة وصورة السند المرفوعة بجانب رقم العملية لتأكيد الطلب بنقرة واحدة.

- إدارة المخزون، المنتجات، العروض، وتعديل البنرات والشريط المتحرك.

==================================================

7. التقنيات البرمجية المقترحة

==================================================

- الواجهة: React.js / Next.js مع Tailwind CSS و Framer Motion.

- الرسوم التفاعلية: Spline / Three.js / React-Parallax-Tilt.

- الخرائط: Leaflet / Google Maps API.

- اتجاه الواجهة: RTL كامل باللغة العربية، متجاوب 100% مع كافة الشاشات (الجوال أولاً).

## تشغيل المشروع محلياً (Local Development)

لتشغيل المشروع على جهازك:

```sh
# تثبيت الحزم والمكتبات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build
```
